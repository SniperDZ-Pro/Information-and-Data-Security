# Information and Data Security

This repository provides the official course materials for **Information and Data Security**. It is intended for students studying computer security, cybersecurity, information protection, and related computing disciplines.

The repository is organized by chapter. Each chapter may contain two complementary components:

- **Theory** — academic lecture material covering the fundamental concepts, principles, threats, security objectives, and defensive approaches.
- **Practical Work** — exercises, demonstrations, case studies, and laboratory activities designed to reinforce the theoretical material.

The materials are primarily distributed as **PDF documents** for convenient classroom use and independent study.

---

## Course Materials

### Chapter 1 — Foundations of Information, Data and Computer Security

**Status: Available**

Chapter 1 introduces the foundations required for the remainder of the course, including information security concepts, information assets, threats, vulnerabilities, attacks, risk, security objectives, controls, security domains, and modern cybersecurity challenges.

Available materials:

- **Chapter 1 — Theory**
  - *Foundations of Information, Data and Computer Security*
- **Chapter 1 — Practical Work**
  - Practical exercises supporting the concepts introduced in the theoretical chapter


### Recommended Use

Students are encouraged to:
1. Read the theoretical chapter before the practical session.
2. Review the definitions, diagrams, tables, and security concepts.
3. Complete the associated practical exercises.
4. Keep screenshots, observations, and results when a practical report is required.
5. Use all security tools and exercises only within authorized educational environments.

### Academic Use

These materials are provided for educational and academic purposes as part of the Information and Data Security course.
Practical cybersecurity activities must be performed only on systems, files, networks, and accounts for which the student has explicit authorization.
